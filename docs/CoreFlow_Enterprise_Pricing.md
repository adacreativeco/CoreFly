# CoreFlow Kurumsal Fiyatlandırma

*Fiyatlandırma Modeli: Kullanıcı Başına (Per Seat) + Modül Eklentileri.*

| Paket Özelliği | **CORE** (Başlangıç) | **GROWTH** (Büyüme) | **ENTERPRISE** (Kurumsal) |
| :--- | :--- | :--- | :--- |
| **Hedef Kitle** | Küçük ekipler, yerel dernekler. | KOBİ'ler, orta ölçekli STK'lar. | Büyük kurumlar, Partiler, Holdingler. |
| **Kullanıcı Sayısı** | 50'ye kadar | 500'e kadar | Sınırsız |
| **Fiyatlama (Tahmini)** | $3 / kullanıcı / ay | $5 / kullanıcı / ay | Özel Teklif |
| **Temel Modüller** | Auth, Dashboard, Duyurular, Dokümanlar (Temel), Takvim. | Core + Görevler, Projeler, Mesajlaşma, İK (Temel). | Tüm Modüller + Audit Log, Gelişmiş Güvenlik. |
| **Dikey Modüller** | Ek Ücretli | Ek Ücretli (%20 indirimli) | Pakete Dahil / Pazarlık |
| **Depolama** | 10 GB | 100 GB | 1 TB+ |
| **Destek** | Email | Email + Chat | 7/24 Telefon + Özel Müşteri Temsilcisi |
| **Kurulum** | Cloud (Shared) | Cloud (Shared) | On-Premise veya Private Cloud |
| **SSO / LDAP** | ❌ | ✅ | ✅ |
